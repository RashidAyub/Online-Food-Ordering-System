# 🍕 Food Paradise - Online Food Ordering System

A professional and modern online food ordering website built with HTML5, CSS3, and JavaScript.

## 🎯 Features

- **Responsive Design**: Works seamlessly on Mobile, Tablet & Desktop
- **Modern UI/UX**: Clean and user-friendly interface
- **Smooth Animations**: AOS animations for better user experience
- **Sticky Navbar**: Easy navigation throughout the site
- **Hero Section**: Eye-catching landing section
- **Interactive Elements**: Smooth scroll, active links, mobile menu

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Poppins, Playfair Display)
- AOS Animation Library
